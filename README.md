# PrintAxis - Paper & Printing Solutions Landing Page

A modern, high-performance single-page landing page for **PrintAxis**, a full-service printing and packaging company. Crafted with Next.js 16 App Router, React 19, Tailwind CSS v4, Framer Motion, and native accessible disclosures.

---

## 🎨 Design & Aesthetic

- **Primary Brand Accents:** `#cb5855`, `#ba4f4c`, `#c85956` (Crimson & Terracotta)
- **Deep Slate/Eggplant Neutrals:** `#241121`, `#261021`, `#2e1b2f`
- **Backgrounds:** Clean, airy white and `#fdfaf9` with warm tint blurs
- **Typography:** Poppins and Roboto

---

## 🚀 Key Landing Page Sections

1. **Topbar & Sticky Navbar**
   - Direct business hours, contact numbers, email, and social channels
   - Smooth navigation anchors: `#home`, `#about`, `#services`, `#process`, `#testimonials`, `#blog`, `#faqs`
   - High-contrast "GET A QUOTE" CTA button with hover animation

2. **Hero Section (`#home`)**
   - High-impact headline with photographic backdrop and gradient overlay
   - Value propositions: Premium Print Quality, Fast Turnaround, Dedicated Support
   - Direct links to `#services` and `#cta`

3. **About Section (`#about`)**
   - Comprehensive company background, state-of-the-art machinery highlights, and curated print samples

4. **Services Showcase (`#services`)**
   - Interactive service cards: Digital Printing, 3D Prototyping, Offset Printing, Design & Branding, Packaging & Boxes, Apparel Printing

5. **Step-by-Step Process (`#process`)**
   - 4-stage visual pipeline: Consultation, Design & Proofing, Precision Printing, and Express Delivery

6. **Client Testimonials (`#testimonials`)**
   - Verified feedback from corporate brands and creative directors with star ratings and client avatars

7. **Call to Action / Quote Request (`#cta`)**
   - High-converting custom printing quote banner with direct enquiry triggers

8. **Latest Blogs & Industry Insights (`#blog`)**
   - Informative packaging, stationery, and branding design articles

9. **Frequently Asked Questions (`#faqs`)**
   - Accessible, keyboard-friendly accordion powered by HTML `<details>` and `<summary>` elements with exclusive grouping (`name="printaxis-faq"`)
   - Covers artwork file specs (vector PDF, 300 DPI CMYK), turnaround times, proofing, MOQs, and eco-friendly FSC stocks
   - Embedded support card with direct telephone and email links

10. **Footer**
    - Brand description, quick anchor links, service shortcuts, phone/email contact details, and social links

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** Custom SVG Icon library

---

## 🏃 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
npm run start
```
